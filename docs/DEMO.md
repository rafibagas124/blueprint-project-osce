# Panduan Demo & Pengujian OSCE Center 3D

1. **Jalankan Aplikasi Mode Demo**:
   ```bash
   npm run demo
   ```
2. **Akses Kredensial Pengujian**:
   - URL: `http://localhost:8080/blueprint.html`
   - Kredensial koordinator dan 20 mahasiswa dibuat acak setiap eksekusi.
   - Tabel akun tercetak di terminal dan disimpan di `data/demo-credentials.txt`.
3. **Login Mahasiswa**:
   - Pilih peran **Mahasiswa**, masukkan NIM (contoh `DEV-001`) dan Token Ujian.
4. **Login Koordinator**:
   - Pilih peran **Dosen / Asesor**, masukkan username `dev-koordinator` dan Password acak.
